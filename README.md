# Plan H 데모 프로토타입

한국외국어대학교 학생을 위한 AI 학업 관리 애플리케이션 데모입니다. 실제 학교 시스템이나 외부 API와 연결하지 않고, 로컬 mock data와 규칙 기반 로직으로 동작합니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 Vite가 안내하는 로컬 주소를 열면 모바일 앱 형태의 시연 화면을 볼 수 있습니다.

## 구현된 기능

- 온보딩 정보 입력 및 `localStorage` 저장
- 데모 정보로 시작하기
- 홈 졸업 진행률, 졸업요건 상세 펼침, 이수 완료 반영
- 졸업요건 상세 화면
- 학기별 로드맵, 과목 추가/삭제/학기 이동, 추천 이유 보기
- Plan A/B/C 시간표 전환
- 수강신청 실패 반영, 대체 과목 추천, Plan 적용
- 월간 캘린더, 날짜별 일정 조회, 새 일정 추가
- AI 상담 추천 질문, 규칙 기반 답변, 근거 문서 요약 모달
- 전체 데모 데이터 초기화

## 데이터와 계산

샘플 데이터는 `src/data/mockData.js`에 있습니다. 졸업 진행률과 부족 학점 계산은 `src/utils/graduation.js`에서 처리합니다. 실제 학칙과 다를 수 있으며 발표용 데모에 맞춘 예시입니다.

## 미구현 사항

실제 한국외국어대학교 수강신청 시스템, 학사 서버, LLM API, 외부 캘린더와의 연동은 구현하지 않았습니다.
